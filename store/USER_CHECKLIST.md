# ezSMB 上架操作清单

先完成第 1–3 项，随后即可继续真机验收。账号和备案可以与测试并行。不要把身份证、密码、完整私钥发到聊天或公开仓库。

## 1. 保存发布密钥（必须由你选择保存位置）

- [ ] 在电脑打开 `%USERPROFILE%\.android\ezsmb-release`，将整个目录备份到你控制的加密离线存储。里面包含签名密钥和密码配置，不要上传 GitHub 或普通共享网盘。
- [ ] 保留一份独立备份；确认 `ezsmb-release.jks`、`signing.json` 都在。以后的 APK 更新要继续用这把签名密钥。

## 2. 连接手机，处理首次正式签名安装

- [ ] USB 连接 vivo，解锁，允许 USB 调试，看到电脑授权弹窗时确认；完成后告诉我“手机已授权”。我可以继续检查安装、截图、隐私提示和传输流程。
- [ ] 如果手机仍装着开发 Debug 版，**先不要卸载**。它与公开 Release 签名不同，不能覆盖。可以优先使用另一台空白测试手机；如果只能用当前手机，先记下需要保留的设备/收藏，确认能重新输入服务器密码，再明确告诉我允许卸载旧版。应用私有配置会随卸载丢失，系统 Download/ezSMB 文件应仍保留。
- [ ] 安装时 vivo 若弹出确认，亲自在手机上允许。只安装 `01-packages/ezsmb-0.3.1.apk`，不要安装 androidTest 测试包。

## 3. 提供干净的测试共享

- [ ] 准备一个专用共享目录，放不含隐私的图片、短视频、中文文件名和大文件，给测试账户读写权限；保留 SMB2/3、密码保护和签名设置。
- [ ] 手机与电脑连可互访的局域网。账号密码直接在手机填写，不必发给我。
- [ ] 安装并连接后告诉我可继续测试。我可以截取真实的首页/文件夹/传输页面，制作上架截图和前台服务演示。已有私人目录截图不会直接拿去公开。

## 4. Google Play 开发者账户

- [ ] 打开 https://play.google.com/console/signup ，使用你控制的 Google 账号。按真实身份选择个人或组织，完成身份、联系信息、平台要求的设备验证及收费步骤。不要为了绕过测试选择不符合真实身份的类型。
- [ ] 完成后打开 Play Console，创建应用：名称 ezSMB，应用类型“应用”，免费，默认语言按你的发布范围选择。身份、协议确认和付款由你本人完成。
- [ ] 上传之前先确定 Play App Signing：如希望 Play 与国内 APK 使用相同应用签名，选择导入已有签名的相应选项，按控制台给出的 PEPK 命令导出。**暂不要直接确认由 Google 新建另一把应用签名**。把页面显示的导出步骤交给我，我可以在本地生成导出包；不要贴出密钥密码。上传密钥与最终应用签名是两个概念。[官方说明](https://developer.android.com/studio/publish/app-signing)
- [ ] 将 `01-packages/ezsmb-0.3.1.aab` 上传到内部测试。若 versionCode 6 已被占用，告诉我后台提示，我会递增并重建，不重复上传不同内容的同版本包。
- [ ] 商店详情：复制 `03-documents/text/` 下的标题、简介和详细说明；支持邮箱填 candlepower1112@gmail.com；隐私政策填 https://ezsmb.candlepower.cool/privacy/ 。上传 `02-artwork/icon-512.png` 和 `feature-1024x500-zh.png`。
- [ ] 手机截图等第 2–3 项完成后再传，不能使用网页示意图代替截图。按 `review/declarations.md` 填前台服务、权限、广告和数据安全；按 `review/reviewer-instructions.md` 填应用访问条件，并确认审核方能访问测试 SMB 环境。
- [ ] 处理后台预发布报告和政策提示，保留截图交给我排查。完成 IARC、目标受众、国家/地区等真实选择后，先发布内部测试。
- [ ] 若账户适用新个人开发者要求，邀请至少 12 名真实测试者连续参加 14 天封闭测试，再申请生产访问；不能用自动化或虚构测试记录替代。具体以后台显示为准。[官方测试要求](https://support.google.com/googleplay/android-developer/answer/14151465)

## 5. 国内商店：先做 vivo，再复用材料

- [ ] 打开 https://dev.vivo.com.cn/ ，注册并按真实主体完成开发者认证；随后可在 https://dev.mi.com/ 、https://open.oppomobile.com/ 、https://developer.huawei.com/ 、https://open.qq.com/ 注册对应平台。
- [ ] 在各后台查看“工具/文件管理”类是否接受你的主体类型，以及要求的软件著作权或权属证明、APP 备案材料。将具体必填项目发给我；我可以整理源码说明和材料草稿，不能替你实名认证或出具证书。
- [ ] 向服务器接入商确认官网域名的现有 ICP 备案覆盖情况，并向商店/接入商确认本地局域网工具的 APP 备案适用流程。不要编造编号，也不要因为开源就假定豁免。[工信部通知](https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2023/art_dd783a581c9644a4aee10afa582811db.html)
- [ ] 新建应用后上传 `01-packages/ezsmb-0.3.1.apk`。包名填 com.ezsmb.app，版本 0.3.1，开发者展示名 CandlePower（法律主体按认证结果），其他文案和隐私链接同上。
- [ ] 如要求证书指纹，使用 `01-packages/signing-certificate.txt`；不要上传 `.jks` 或 `signing.json`。国内素材规格各异，把后台规格交给我即可调整，先不硬裁剪真实截图。
- [ ] 提交隐私检测和审核，按真实审核结果修复；没有审核通过前不要在官网添加“已上架”或商店下载徽章。

## 你完成后如何交接

告诉我“手机已授权”，或说明已到哪个后台页面即可。页面的普通字段和报错可以截图；密码、验证码、身份材料在平台上由你本人输入。还没有开发者账户时，先做密钥备份与真机验证也可以。
