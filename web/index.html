电脑的共享文件夹。

电脑已经开了共享，手机就应该能直接访问。ezSMB 是一个 Android 小工具，用来找局域网里的电脑、浏览文件，以及上传和下载。

Windows 共享、Samba 和 NAS 都使用 SMB 协议。电脑端不用再装一个配套程序。

日常怎么用

手机和电脑需要在可互访的局域网里。

打开，找电脑
首页自动查找 SMB 设备，也会记住连接过的电脑。点设备后用电脑账户登录；允许匿名访问的共享会出现匿名入口。
进文件夹
连上后列出共享目录。图片和视频可以看缩略图，文件夹也会尝试用里面的媒体做封面。经常用的目录可以收藏到首页。
点文件下载
下载进度在底部显示，完成后可以打开文件或所在目录。要往电脑传文件，就在目标目录点「上传」，用系统选择器选文件。
下载保存到内部存储 / Download / ezSMB

原生 Kotlin + Compose，支持 Material You 动态配色和深色模式。没有广告、统计 SDK 或云账户；文件直接在你的设备之间传输。

连接时容易卡住的地方

没有找到电脑

先看电脑是否休眠、文件共享是否开启。访客 Wi-Fi 或 AP 隔离会让设备彼此不可见。可以在「手动连接」里输入电脑 IP 试一次。

Windows 共享设置和连接排查

用户名密码没错，还是登录失败

Windows Hello PIN 不是账户密码。共享权限和文件夹的安全权限也都要允许这个账户访问。不要为了连接关闭防火墙或 SMB 签名。

电脑重启，地址变了

相同服务器标识可以帮助找回新 IP，但服务器重启也可能改变标识。这时重新关联收藏即可。长期使用，建议在路由器上给电脑保留一个 DHCP 地址。
