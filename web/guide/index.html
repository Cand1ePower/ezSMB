把电脑的共享文件夹，
连接到手机。

手机和电脑需要处在可互访的局域网。连接同一 Wi-Fi 名称并不总代表能互访，访客网络、AP 隔离和 VPN 路由都可能影响连接。

在 Windows 11 设置共享

  1. 在可信家庭网络中，将 Windows 网络配置文件设为「专用」。在高级共享设置中开启专用网络的网络发现、文件和打印机共享。
  2. 选择需要共享的文件夹，打开属性中的「共享」或「高级共享」。设置共享名，并只授予需要使用的账户权限。下载需要读取权限；上传还需要更改或写入权限。
  3. 同时检查文件夹「安全」选项卡的文件系统权限。共享权限和文件系统权限共同决定实际访问范围。
  4. 保留密码保护共享。准备电脑账户的真实密码；Windows Hello PIN 不是 SMB 密码。本地账户可使用「计算机名\用户名」，域账户按管理员给出的域名配置。
  5. 在 Windows 防火墙中允许专用网络的「文件和打印机共享」。不要关闭整个防火墙，也不要把 TCP 445 转发到互联网。
  6. 打开 ezSMB，选择电脑并输入账户密码。认证成功后打开共享文件夹。看不到共享列表时，在菜单的手动共享入口输入共享名。

微软官方说明：通过网络共享文件。不同系统版本的设置名称可能略有差异。

连接 NAS 或 Linux Samba

在设备管理页面开启 SMB2/SMB3 服务，为专用账户授予目标共享文件夹权限。使用该账户连接。无需启用 SMB1，也无需关闭 SMB 签名。访客访问是否可用由服务器策略决定，ezSMB 只有探测到实际可读取的匿名共享才显示匿名连接入口。

没有自动找到设备

确认电脑未休眠、共享服务已开启，手机与电脑可互访。在 ezSMB「手动连接」输入电脑 IP、可解析的主机名，或 smb://主机/共享名/子目录。不要在地址中加入用户名或密码。

如果手动也无法连接，请检查目标地址、专用网络防火墙规则、访客 Wi-Fi 隔离及 VPN。应用只扫描有限数量的局域网地址，大网段可能无法完整发现。

IP 地址变了

ezSMB 可在发现相同服务器 GUID 时更新地址。电脑或 SMB 服务重启也可能改变 GUID，此时使用收藏的「重新关联设备」，重新验证账户和目录。跨网络不会仅凭同名电脑自动发送已保存密码。

更稳定的办法是在路由器设置 DHCP 地址保留，让同一电脑获得固定租约地址。具体入口请查阅路由器说明，不要随意选择可能已被其他设备使用的静态 IP。

下载在哪，失败怎么办

下载在手机内部存储的 Download/ezSMB，系统可能将 Download 显示为「下载」。可通过完成任务的「打开目录」或菜单进入。部分厂商文件管理器不支持初始目录提示，需要手动打开该目录。

失败或取消不会将部分文件标为完成。网络恢复后可从头重试，当前不支持断点续传。上传中断且远端清理失败时，可能留下本任务的 .ezsmb-part- 临时文件；确认没有正在进行的对应任务后再处理。
